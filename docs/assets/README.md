# AIAT visual assets

This directory contains repository-owned visual assets used to make the GitHub
landing page and architecture documentation easier to scan.

| Asset | Purpose | Provenance |
| --- | --- | --- |
| [`branding/aiat-header.svg`](branding/aiat-header.svg) | README header banner and AIAT visual signature | Original AIAT-authored SVG geometry |
| [`architecture/aiat-system-map.svg`](architecture/aiat-system-map.svg) | High-level control-plane and worker boundary map | Original AIAT-authored SVG geometry |

The assets use system font fallbacks and contain no remote image, tracking code,
stock photography, model output, or copied third-party artwork. Unless a future
asset states otherwise, they are covered by the repository's [`LICENSE`](../../LICENSE)
and are not third-party components. The presentation system is maintained in
[`DESIGN.md`](../../DESIGN.md).

Keep the assets aligned with the maintained architecture. Update the system map
when ownership, authority, state, evidence, or adapter boundaries change; do not
use it as a substitute for the normative architecture documentation.
