# Archived root documents

This directory keeps historical design inputs that were previously stored at
the repository root. They remain available for provenance and context, but
they are not current implementation, deployment, or release authority.

For current guidance, use:

- [`AIAT_TARGET_PROGRAMME.md`](../../AIAT_TARGET_PROGRAMME.md) for programme
  authority and architecture direction;
- [`ROADMAP.md`](../../ROADMAP.md) for delivery navigation;
- [`../current/`](../current/) for maintained feature specifications and
  status documents;
- [`../../README.md`](../../README.md) and [`../../mas/README.md`](../../mas/README.md)
  for setup and runtime instructions.

The files are retained rather than deleted so that earlier decisions and
evidence remain traceable. New work should update the maintained programme,
roadmap, feature specifications, and release ledgers instead of adding another
root-level draft.
